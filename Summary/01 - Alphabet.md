## Phonetic Alphabet (NATO)

The NATO phonetic alphabet is used to spell words clearly in communication, especially over the phone or radio. Each letter has a code word to avoid confusion between similar-sounding letters (e.g., B and P, M and N).

| Letter | Code Word |
|--------|-----------|
| A      | Alpha     |
| B      | Bravo     |
| C      | Charlie   |
| D      | Delta     |
| E      | Echo      |
| F      | Foxtrot   |
| G      | Golf      |
| H      | Hotel     |
| I      | India     |
| J      | Juliet    |
| K      | Kilo      |
| L      | Lima      |
| M      | Mike      |
| N      | November  |
| O      | Oscar     |
| P      | Papa      |
| Q      | Quebec    |
| R      | Romeo     |
| S      | Sierra    |
| T      | Tango     |
| U      | Uniform   |
| V      | Victor    |
| W      | Whiskey   |
| X      | X-ray     |
| Y      | Yankee    |
| Z      | Zulu      |

**Examples of Use**

- **Spelling a name:** "My name is John. J - Juliet, O - Oscar, H - Hotel, N - November."
- **Spelling an email:** "My email is hello@gmail.com. H - Hotel, E - Echo, L - Lima, L - Lima, O - Oscar."

## Vowels vs. Consonants

The English alphabet has 26 letters. They are divided into vowels and consonants.

| Type | Letters | Count |
|------|---------|-------|
| **Vowels** | A, E, I, O, U | 5 |
| **Consonants** | B, C, D, F, G, H, J, K, L, M, N, P, Q, R, S, T, V, W, X, Y, Z | 21 |

> **Note:** The letter **Y** can sometimes act as a vowel (as in "myth" or "gym").
